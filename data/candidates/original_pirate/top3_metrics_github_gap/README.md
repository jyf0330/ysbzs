# Top-three metrics GitHub evidence gap

This audit binds the observed Vanessa candidate rows `222`, `180`, and `219`
to the exact BazaarPlusPlus snapshot hashes and to an immutable public consumer
commit. The consumer proves that a build ID is only the zero-based array index
of that particular snapshot and that the public build schema omits skills.

The public uploader can capture skill card sets, but the published build rows do
not bind those skills to a row. Its run facts expose a build channel and mod
version, not the original game client version. The public repository also does
not publish the analyzer query, filters, grouping key, denominator, or a stable
row identifier. Therefore these rows remain candidates and cannot authorize
the six original-rules battle logs.
